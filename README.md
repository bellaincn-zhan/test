# Motorcycle FAQ Center

This repository contains planning documents for a motorcycle FAQ Center aimed at international buyers, importers, dealers, distributors, and OEM/ODM partners.

## Open the FAQ Center

Open `index.html` in a browser to view the FAQ Center as a static page with navigation, expandable groups, and search.

If you are browsing on GitHub and cannot see the new files yet, switch to the `cursor/add-faq-center-4fe6` branch or wait until the pull request is merged into `main`.

## Documents

- [Static FAQ page](index.html): browser-friendly FAQ Center page.
- [Website SEO/GEO Upload Plan](FAQ_WEBSITE_SEO_GEO_PLAN.md): implementation plan for uploading FAQ pages to the website with SEO, GEO, schema, URL, and internal linking guidance.
- [FAQ SEO/GEO Upload CSV](FAQ_SEO_GEO_UPLOAD_PLAN.csv): CMS-ready plan for 943 FAQ question pages, including H1, SEO title, meta description, URL, canonical, breadcrumb, schema type, CTA, and internal links.
- [FAQ Category URL Map](FAQ_CATEGORY_URL_MAP.csv): URL and metadata map for 108 FAQ hub, section, and group pages.
- [FAQ Center](FAQ_CENTER.md): full FAQ taxonomy and topic hierarchy.
- [FAQ Search-Intent Question Bank](FAQ_SEARCH_INTENT_QUESTION_BANK.md): professional B2B FAQ questions rewritten around buyer search intent from Google-style, AI-answer, forum, and importer discussion patterns.
- [FAQ Content Guide](FAQ_CONTENT_GUIDE.md): URL structure, content model, article templates, writing guidelines, rollout priorities, and sample FAQ drafts.

## Content Recommendation

Use `FAQ_CENTER.md` as the category structure, then use `FAQ_SEARCH_INTENT_QUESTION_BANK.md` and `FAQ_SEO_GEO_UPLOAD_PLAN.csv` for final article titles, URLs, metadata, schema, and internal links. Search-facing FAQ pages should be written as natural buyer questions instead of short topic labels.
